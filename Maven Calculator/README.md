# JavaFX Maven Calculator

This is a JavaFX based calculator project managed with Maven.

## Features
- Basic arithmetic operations (+, -, *, /)
- Advanced operations (Square, Square Root, Reciprocal, Percent)
- Error handling (Division by zero, Invalid input)
- UI Tests using TestFX

## How to Run
```bash
mvn javafx:run
```

## How to Test
```bash
mvn test
```
